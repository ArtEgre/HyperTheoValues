# Value design rules

The current catalogue is the original 66 TheoValues values plus Palamite Panentheism and Eastern Syriac. Expansion values were removed at the user's request; do not reintroduce them merely to complete denomination profiles.

These rules record the user's requirement that new values must not duplicate or subsume existing values.

- A new scored value must introduce a distinct theological position, not a new name for an existing one or a denomination-branded version of it.
- Do not add broad umbrella values that also describe several existing alternatives. Shared affirmations belong in denomination notes.
- Compare a proposed value against every existing value in its category. State the deciding distinction and cite the source before adding it.
- Keep each category's question at a consistent level. An unspecified view on a detail is not another theological position.
- Merge synonyms and equivalents into a single canonical value. Update all question paths, profile definitions, sources, and saved-answer aliases together.
- Do not force complete scored profiles by inventing a doctrinal assignment. A sourced descriptive note is preferable when no narrower value is warranted.
- Compatibility is different from duplication: distinct claims can coexist. For example, the Father's monarchy and essence–energies participation address different questions; their compatibility does not make them synonyms.
- Keep the user-requested Eastern Syriac formulation and conditional Eastern/Oriental Orthodox composite behavior.

Retired IDs and canonical replacements are recorded in valueAliases in data.js. A null replacement means the old umbrella was removed without inferring a narrower belief.

## Label style

Prefer specific, established doctrinal names ending in -ism when they accurately identify the position. Keep established exceptions, including Eastern Syriac, Theosis, Prima Scriptura, Sola Scriptura, Nuda Scriptura, and Transubstantiation. Do not invent a suffix or rename a doctrine as a different theory to meet a spelling rule. Use a precise tradition-qualified name where no established -ism term fits. Display-label changes must not create another scored value or alter its definition.
